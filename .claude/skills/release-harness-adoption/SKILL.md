# Release-Harness lifecycle

Read `.release-harness/protocol/LIFECYCLE.md` in an installed project, or
`protocol/LIFECYCLE.md` in this repository, and follow it.

Run `release-harness lifecycle status` before broad repository inspection. Use
only public Release-Harness commands. The deterministic core owns identity,
freshness, eligibility, execution, evidence sealing, attribution, and verdict.
This adapter owns no lifecycle or contract semantics.
