THE TRUST MODEL

Intelligence can investigate. Only evidence can decide.

Release-Harness pairs an AI Intelligence Layer with a Deterministic Core Engine — pure Node.js/Playwright/Docker with zero prompts and zero hallucinations.

  1. 01Project source.git tree (immutable)
  2. 02MaterializerIsolated scratchpad
  3. 03Compose & PlaywrightOrigins + Egress Filter
  4. 04Sealer & verdictSHA-256 Manifest

An AI agent cannot prompt or talk a release into being green. If an agent modifies an evidence file or injects fake results, the SHA-256 evidence manifest checksum mismatch triggers an immediate EVIDENCE_INVALID (Exit 4).

VERDICT REGISTER

Five exit codes. No ambiguous green.

The evaluator derives the outcome from what happened, not from a report of what happened.

0
PASS

All required & conditional scenarios passed with verified side effects.

Ready for promotion / deployment.
1
FAIL

One or more required scenarios failed due to product bugs or missing dependencies.

Patch code.
2
UNPROVEN

Preconditions unmet, active waivers present, or dirty git tree with --allow-dirty.

Stage missing fixtures or commit changes.
3
HARNESS_ERROR

Malformed scenario, missing runtime environment, or Docker Compose crash.

Verify prerequisites and Compose configuration.
4
EVIDENCE_INVALID

Evidence file tampering, injected logs, or SHA-256 checksum mismatch.

Clean corrupted workspace.
